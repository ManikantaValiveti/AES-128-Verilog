# AES-128 Encryption Hardware Implementation

## Overview

This project implements the **Advanced Encryption Standard (AES-128)**
encryption algorithm in **Verilog HDL** and was developed and simulated
using **Xilinx Vivado**.

The design accepts: - A **128-bit plaintext** - A **128-bit encryption
key**

and produces a **128-bit ciphertext**.

The implementation is organized around the standard AES-128
transformation stages and includes a dedicated key expansion module.

------------------------------------------------------------------------

## AES-128 Architecture

The design consists of:

1.  **Key Expansion**
2.  **Initial AddRoundKey**
3.  **Rounds 1--9**
    -   SubBytes
    -   ShiftRows
    -   MixColumns
    -   AddRoundKey
4.  **Final Round (Round 10)**
    -   SubBytes
    -   ShiftRows
    -   AddRoundKey

The RTL schematic generated by Vivado shows the key expansion and the
complete sequence of AES rounds.

------------------------------------------------------------------------

## RTL Modules

  Module             Function
  ------------------ ----------------------------------------
  `topmodule.v`      Top-level AES-128 encryption module
  `keyexpansion.v`   Generates the AES round keys
  `sub_bytes.v`      Performs the SubBytes transformation
  `shift_rows.v`     Performs the ShiftRows transformation
  `mix_columns.v`    Performs the MixColumns transformation
  `addroundkey.v`    Performs the AddRoundKey operation
  `aes_tb.v`         Testbench used for simulation

## Simulation / Verification

The implementation was verified using the standard AES-128 test vector.

### Input

**Plaintext**

``` text
00112233445566778899AABBCCDDEEFF
```

**Key**

``` text
000102030405060708090A0B0C0D0E0F
```

### Output

**Ciphertext**

``` text
69C4E0D86A7B0430D8CDB78070B4C55A
```

The simulated `state_out` matches the expected AES-128 ciphertext.

## How to Run

1.  Open **Xilinx Vivado**.
2.  Create or open a Verilog project.
3.  Add all files from the `rtl/` directory.
4.  Add `testbench/aes_tb.v` as the simulation source.
5.  Set the appropriate top module.
6.  Run **Behavioral Simulation**.
7.  Observe `state_in`, `key`, and `state_out` in the waveform.
8.  Compare the resulting ciphertext with the expected AES-128 test
    vector.
